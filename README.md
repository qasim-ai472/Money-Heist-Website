# 🎭 Money Heist: La Resistencia Portal

A cinematic, high-contrast web interface inspired by the Netflix series **"La Casa De Papel"** (Money Heist). This project is a frontend clone designed to showcase modern web development techniques, specifically focusing on immersive UI/UX and smooth user interactions.

---

## 🛠️ Tech Stack
* **HTML5:** Semantic structure for high accessibility.
* **CSS3:** Custom animations, Flexbox, CSS Grid, and Glassmorphism effects.
* **JavaScript (ES6+):** DOM manipulation, smooth scroll logic, and Intersection Observer API for scroll animations.

---

## ✨ Key Features

### 🎬 Cinematic UI
* **High-Contrast Aesthetic:** A strict "Heist Red" and "Pitch Black" color palette.
* **Blueprint Background:** A subtle grid overlay that mimics the Professor’s strategy board.
* **Glitch Typography:** Heading styles that reflect the rebellious nature of the show.

### 👤 Interactive Crew Grid
* **Dossier Cards:** Character cards for Tokyo, Berlin, Denver, and more.
* **Hover Effects:** Cards transition from grayscale to full color with a red glowing border upon user interaction.

### 📜 Technical Highlights
* **Intersection Observer:** Elements "Reveal" themselves as you scroll down, improving performance and visual flow.
* **Sticky Navigation:** A glassmorphism navbar that changes opacity and size dynamically based on scroll position.
* **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop views.
